# 1. Scope проекта

## In Scope

- Открытие брокерского счёта существующим клиентом мобильного банка.
- Сбор обязательных согласий.
- Создание и отправка заявки.
- Проверка обязательных данных.
- Отслеживание статуса заявки.
- Создание брокерского счёта после успешной проверки.
- Отображение ошибок и необходимости предоставить дополнительные сведения.
- История изменения статусов заявки.

## Out of Scope

- Торговля ценными бумагами.
- Пополнение брокерского счёта.
- Вывод денежных средств.
- Налоговая отчётность.
- Маржинальное кредитование.
- Подбор инвестиционных рекомендаций.
- Идентификация нового клиента банка с нуля.

## Допущения

- Пользователь уже является клиентом банка.
- Пользователь прошёл базовую идентификацию.
- В мобильном приложении есть авторизация.
- Проверки клиента могут выполняться внешними или внутренними сервисами.

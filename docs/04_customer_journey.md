# 4. Customer Journey Map

| Этап | Действие клиента | Действие системы | Возможная проблема | Улучшение |
|---|---|---|---|---|
| 1. Старт | Нажимает «Открыть брокерский счёт» | Проверяет доступность | Непонятно, зачем нужны проверки | Показать короткое пояснение |
| 2. Условия | Читает условия | Показывает ключевые условия | Слишком много текста | Краткое summary + ссылка на полный документ |
| 3. Данные | Проверяет персональные данные | Предзаполняет данные | Неактуальные данные | Позволить перейти к обновлению профиля |
| 4. Согласия | Подтверждает согласия | Сохраняет версии документов и timestamp | Много чекбоксов | Группировать согласия по смыслу |
| 5. Отправка | Нажимает «Отправить» | Валидирует и создаёт процесс рассмотрения | Неясен срок | Показывать ожидаемый SLA |
| 6. Рассмотрение | Ждёт результат | Меняет статусы | Пользователь не понимает прогресс | Таймлайн статусов |
| 7. Результат | Получает решение | Создаёт счёт / отображает отказ | Сухое сообщение об ошибке | Чёткий next step |
